CMB1511 - hover bike: controls back to GHOST, turn strengthened again

You were right that the dynamic was fine and the mapping was the problem. The front-steer carve is
untouched; only the control scheme reverts. Left stick throttle+strafe, right stick turns, right
deep-up fires - exactly as before the experiment. The left-stick-drives scheme is still there behind
window._BIKE_CTRL='skate' rather than deleted, in case any of it is worth stealing later.

TURNING, THIRD PASS
In a front-steer model the rate is v/R, so tightening R lifts the whole curve - but the bottom end
is set by the speed-INDEPENDENT pivot term, so both had to move or it would only get sharper where
it was already sharpest. R ~161 -> ~132, standstill authority 0.55 -> 0.85.

  full lock                  full speed      half speed
    original tank            119 deg/s       82 deg/s
    front-steer, 1st pass    128             47          <- the "way too slow" one
    2nd pass                 231             93
    now                      287             114
    radius                   173 -> 142      136 -> 103

It now turns harder than the tank ever did at both ends (2.4x at speed, 1.4x at half) while keeping
the carve - the radius still holds as speed changes instead of the vehicle pivoting on the spot.

Knobs if it wants another nudge: _BIKE_WHEELBASE (lower = tighter), _BIKE_STEER_MAX (lock),
_BIKE_PIVOT (how much it answers at a crawl).
